A) Requirements - top

This extension needs:

  • PHP 7.1
  • GMP PHP extension
  • mbstring PHP extension
  • curl PHP extension
  • OpenSSL PHP extension
  • phpBB 3.2.0
  • HTTPS on the domain

B) Installation instructions - top

Since you are reading this help file, you already extracted the archive which is the first step to successful installation. Great!
Next steps are:

  1. Upload directory senky/ to ext/ directory of your board. It is possible that directory senky/ already exists if you are using my other extensions. In that case copy senky/pushnotifications/ to ext/senky/.
  2. Go to ACP of your board, tab Customise.
  3. Find Browser & Mobile Notifications and click Enable next to it.
  4. Done! That was easy, wasn't it? :)
  5. Extension doesn't have any complicated settings, just enjoy.

C) Supported Browsers - top

Push Notifications (as are browser and mobile notifications called technically) are supported by:

  • Google Chrome
  • Mozilla Firefox
  • Edge
  • Opera
  • Chrome for Android
  • Firefox for Android
  • Opera Mobile for Android
  • UC Browser for Android
  • Samsung Internet for Android

Unfortunately, Safari nor any iOS browser is supported due to restrictions by Apple.

D) Usage Guide - top

Browser and Mobile Notifications extension embraces a careful, non-invasive approach by offering a user the option to enable browser notifications only when they are already dealing with notifications. Browser and Mobile Notifications extension options are located in two places, Notification settings in UCP and Notifications dropdown:


By default, notifications are disabled (off). Enabling requires user to interact with a browser popup window requesting a permission to send notifications. This is a security requirement by all browsers. After user grants the permissions, browser notifications are automatically enabled.

There are three possible scenarios when notifications are not delivered:

  • Browser is unsupported. In this case all Browser and Mobile Notifications extension will be hidden.
  • User force-disabled notifications in browser. Browser and Mobile Notifications extension will display a manual on how to re-enable them.
  • User was logged out. Browser and Mobile Notifications extension won't display notification after user was logged out for security reasons.
